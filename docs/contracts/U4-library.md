## B Adapter protocol v1 codec (oracle side; shipped `tool/FvdepCore/Protocol.lean`, pure, Std + `FvdepCore.Json` + `Fvdep.Semver.Version.V1_0_0`; `sigOf` in `tool/FvdepCore/Protocol/Sig.lean`, Lean `Expr` alone)

- B1 Types: `Ty` = `bytes` | `text` | `utf16` | `nat` | `int` | `ordering` | `version`; `RTy` = `plain Ty` | `option Ty`; `Val` = `bytes (List UInt8)` | `text (List Char)` | `utf16 (List UInt16)` | `nat Nat` | `int Int` | `ordering Ordering` | `version Version`; `HasTy x t` = `x.ty = t` (`Val.ty`, one arm per constructor). `Sig` = op name + argument types (≥ 1) + result type. `Reply` = `ok Val` | `err` (an `option` result's `none`, wire `{"err":"none"}`) | `invalid String`; a reply's typing (`ok` typed by the result's inner type) = U5b's evaluator + trace law. `sigOf : Lean.Expr → Option (List Ty × RTy)` maps a spec type (non-dependent arrows over `List UInt8`/`ByteArray` → bytes, `List Char` → text, `List UInt16` → utf16, `Nat`, `Int`, `Ordering`, `Fvdep.Semver.Version.V1_0_0.Version`, result `Option X` → `option`) = C's encodability rule (V3); it reads `Expr` shapes without reduction (a type synonym, `optParam` or another wrapper = not encodable), metadata (`mdata`, which the kernel reads as its body) transparent at every position it reads (reviewer-5 S7: an `mdata`-wrapped codomain arrow was refused).
- B2 Value encodings over J's `Value` (interface §8): bytes = `str` of lowercase hex pairs (`""` = empty); text = `str s` (any scalars; J already refuses an escaped lone surrogate); utf16 = `arr` of `int` 0–65,535; nat = `int n` for n ≤ 2^53 − 1, else `str` = its canonical decimal; int = `int n` for |n| ≤ 2^53 − 1, else `str` = canonical decimal with `-` for negatives (never `-0`); ordering = `"lt"` | `"eq"` | `"gt"`; version = `obj` with exactly `build`, `major`, `minor`, `patch`, `pre` (`pre` = `arr` of one-key `obj`s `num` (nat) | `alnum` (text); `build` = `arr` of text; any texts: `compare` is total). `encodeVal : Val → Value`; `decodeVal : Ty → Value → Option Val` refuses every other value of the whole `Value` domain (an in-range number as a string, an integer beyond ±(2^53 − 1), a leading zero, `+`, a non-integer, a missing or extra key, a tag pair).
- B3 Lines: input bytes split at LF (`\r` before it = J whitespace); each line, the empty one included, is one request; a nonempty final fragment without LF = one request; EOF adds none. A request = J `decode` of its bytes (J1 bounds) → `obj` with exactly `args` (`arr`) + `op` (`str`) → `op` = the target's op name → arity → each argument `decodeVal` at its type; any failure → reply `{"invalid":<reason>}` (free text) and the next line is read. Replies (one per request, canonical J text + LF): `{"ok":<encodeVal result>}`, `{"err":"none"}` (an `option` result's `none`), `{"invalid":<reason>}`. A result prints whole: never clipped, never refused for its size (J4's printer is total; the request bound does not bound the reply, e.g. 98,304-byte hex strings). Interface §8 states: requests = J1 bounds; replies print whole (U8 adds the bounds fvdep reads adapter replies under).
- B4 Claims (`ProtocolClaims`; spec `FvdepAudit.Protocol.Spec`, layouts written from §8 apart): `valLayout` (`encodeVal x = valSpec x`), `valExact` (over every `Value`: `decodeVal t v = some x ↔ x.ty = t ∧ valSpec x = v`), `valValid` (`stringsFit (valSpec x) = true → Valid (encodeVal x)`: integers, depth + key order hold by construction), `requestExact` (`decodeRequest sig b = .ok xs ↔ decode b = .ok (requestLayout sig.op (xs.map valSpec)) ∧ xs.map Val.ty = sig.args`; totality = the result type `Except String (List Val)`: every line → typed arguments or a refusal), `replyExact` (`encodeReply r = (print (replyLayout r)).push 0x0A`), `linesExact` (`(lines b).map (·.data.toList) = linesSpec b.data.toList`), `sigExact` (`sigOf e = some (ts, r) ↔ SigIs e ts r`, the B1 type table over `Expr` shapes written apart). `Forall₂ HasTy xs ts` = `xs.map Val.ty = ts` (core Lean has no `List.Forall₂`). Line loop + one-reply-per-request trace law = U5b (with the loop). `noCaller` = U5b for the codec until U5b wires it; `sigOf`'s = U4 (C calls it).
- B5 Spec driver (`FvdepDev`, never shipped): `fvdep-dev oracle <id>@<ver>` = B3's lines over the six launch specs compiled in; EOF → 0; unknown target → stderr naming it, exit 2, stdin unread; usage → 2.
- B6 Spec evidence (B's commit; tester-1's oracle cases stay unmerged: they grade U5b's `fvdep oracle`): the 14 `oracle.*` cases through `FVDEP_BIN` = a wrapper mapping `oracle …` → `fvdep-dev oracle …`, red first on planted spec mutants (nonzero filling bits accepted, the alphabets' last symbols swapped, `num` above `alnum`, a prefix ordered after its extension, a leading-zero numeric accepted, a reversed comparator), each mutant + the cases it turns red recorded; seeds, sample + exhaustive counts recorded.
