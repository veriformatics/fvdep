- J1 Values: `Value` = `null` | `bool b` | `int n` (`Int`) | `str s` | `arr xs` | `obj ms` (`List (String × Value)`). Depth: a scalar 0, a container 1 + the largest child depth (empty container 1). `Valid v` := every integer |n| ≤ 2^53 − 1 ∧ every string + key ≤ 65,536 UTF-8 bytes ∧ depth ≤ 32 ∧ every object's keys strictly ascend in UTF-8 byte order. A successful decode returns a valid value; the printer is total, its laws hold on valid values. Strings may hold U+0000: consumers crossing path, argv or identifier conventions validate their own semantics (D does for every field it reads).
- J2 Grammar (spec, over bytes): RFC 8259 JSON text = ws value ws, ws ∈ {0x20, 0x09, 0x0A, 0x0D}; any value at top level. Literals `null` `true` `false`. Integer = `0` | `-?[1-9][0-9]*` with |n| ≤ 2^53 − 1 (no `-0`, fraction, exponent, `+`, leading zero; an out-of-range lexeme has no derivation). String = `"` element* `"`, element = an escape (`\"` `\\` `\/` `\b` `\f` `\n` `\r` `\t`, `\uXXXX` either hex case; a high-surrogate escape only immediately followed by a low-surrogate escape, the pair = one scalar; a lone surrogate escape has no derivation) or a raw scalar c ≥ U+0020, c ∉ {`"`, `\`}, as the bytes `String.utf8EncodeChar c` (overlong forms, encoded surrogates, bytes above U+10FFFF, stray continuation bytes: no derivation). Arrays + objects per RFC 8259, ws around tokens; an object denotes its members in text order, duplicates kept (J3 decides). A leading BOM, trailing non-whitespace, raw control characters in strings: no derivation; DEL, escaped NUL, U+2028/U+2029, U+FEFF inside a string, noncharacters = content (not I-JSON).
- J3 Outcome (precedence): `lexicalDepth b > 32` → `tooLarge`; else no derivation → `malformed`; else a string or key over 65,536 UTF-8 bytes → `tooLarge`; else an object holding two members with equal decoded keys → `duplicateKey site`; else `ok (canon v)` (members stably sorted by key bytes, every level). `lexicalDepth` = the largest count of open `[`/`{` outside string literals in a left-to-right byte scan (a closing byte at level 0 stays 0); on a grammatical text it equals the value's depth (proof obligation). `site` = (path, key) over the raw value: the first object in pre-order (an object before its members' values, members in text order, array elements in index order) that repeats a decoded key; key = its least repeated key in UTF-8 byte order; path = the member keys + array indices from the root to that object (unambiguous: an ancestor holding a repeat comes first). The decision stays fvapi's `hasDupKey` (its proofs carried over); the site = an added payload with its own lemmas. Consequences: `x` + 33 `[` → `tooLarge`; an unclosed string holding 33 `[` → `malformed`; a 65,537-byte string then `x` → `malformed`; an over-cap string + a duplicate key → `tooLarge`; a duplicate key then garbage → `malformed`; `{"a":{"b":1,"b":2},"a":3}` → site ([], "a"); `[{"x":1},{"y":1,"y":2,"c":3,"c":4}]` → site ([1], "c").
- J4 Canonical text (spec `canonical : Value → List UInt8`): no whitespace; members in stored order; integers in shortest decimal, `-` only when negative; strings escape exactly `"` → `\"`, `\` → `\\`, U+0008 `\b`, U+000C `\f`, U+000A `\n`, U+000D `\r`, U+0009 `\t`, every other U+0000–U+001F + U+007F → `\u00xx` (lowercase hex); every other scalar raw UTF-8 (`/`, U+2028, U+2029, noncharacters included) = `jq -S -c` without its final LF on every valid value (differential evidence; not JCS: its key order is UTF-16).
- J5 Shipped: `decode : ByteArray → Except DecodeError Value` (`malformed` | `tooLarge` | `duplicateKey (site : List PathSeg × String)`; `PathSeg` = `key s` | `index n`, shared with D5), `print : Value → ByteArray`; `Value.object ms` = stable key-byte sort of `ms` (repeats kept, children untouched); `get? key` = the first equal key's value (absent or non-object → `none`; JSON null → `some .null`; keys = exact scalar sequences); `asStr?` `asInt?` `asBool?` `asArr?` `asObj?` = their constructor's payload, `none` otherwise. No shipped judgment decides by `BEq Value` without a proof that it agrees with `=`. Resources (fvapi J5, unchanged): index reads without copying the input into a list, linear lexical scan, tail-recursive loops, O(N + Σ Kᵢ log(mᵢ + 1)) sorting work, a proven-sufficient fuel bound, no `partial` def reached by a claim.

## F Persistence (port of fvapi F1–F5 + durable replace, project read, writer lock)

- F1 Shim `c/fvdep_sys.c` = single-syscall wrappers, errno returned at once, no retry or policy: `open(path, O_WRONLY|O_CREAT|O_EXCL|O_CLOEXEC|O_NOFOLLOW, mode)`, `open(path, O_RDONLY|O_CLOEXEC)`, `open(path, O_RDONLY|O_DIRECTORY|O_CLOEXEC)`, `read`, `write`, `fsync`, `close`, `rename`, `unlink`, `open(path, O_RDWR|O_CREAT|O_CLOEXEC|O_NOFOLLOW, 0644)` + `flock(fd, LOCK_EX|LOCK_NB)`; libc's dynamic symbols (interposable); plus fvapi's native descriptor guard (closed flag, finalizer close-if-open). Policy = Lean (`tool/FvdepIO/Sys.lean`) over a syscall interface, instantiated with the externs in `IO`; residue `sys-shim` (boundary = the externs + the guard; reason: one syscall each + the guard's lifecycle, tested + sanitized + fuzzed; ruling recorded in Decisions with this unit).
- F2 API (`FvdepIO.Sys`): `Path` = NUL-free (`Path.ofString?`); `Name` = a validated basename (`Name.ofString?`: nonempty, no NUL or `/`, neither `.` nor `..`, ≠ `.fvdep-writer.lock`); fvapi's `Writer` (create/write/sync/close, per-writer guard + closed flag + finalizer close-if-open, never exposing its descriptor) + `syncDir`, unchanged; `replace (dir : Path) (name : Name) (bytes : ByteArray) : IO (Except SysError Unit)` = temp `<dir>/.<name>.tmp-<pid>-<n>` (create-exclusive; EEXIST → next n, ≤ 64 tries; a temp this call never created is never unlinked) → write all → sync → close → `rename(temp, dir/name)` → `syncDir dir`. Cleanup after a failure: every description this call acquired is closed exactly once, then a temp this call created is unlinked (one F3 step, EINTR retries included); the primary error is kept, cleanup failures follow it in order (`SysError` = primary + a list of secondary (op, errno) causes). Target: a failure before any rename attempt leaves the old state (absent or old bytes); an attempted rename that reports failure leaves old or new (rename(2): an NFS server may complete it, then report failure); `syncDir` failing after the rename → error `durability` (target = new; public code `commit_io`).
