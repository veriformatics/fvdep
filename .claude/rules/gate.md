# Gate

- Gate = `tools/vflab-run bash tools/gate.sh` (all fvdep builds, checks + tests run on vflab, shared with fvapi; the desktop runs no fvdep build). Iteration = `tools/vflab-run bash tools/fast-gate.sh` (never the claim). Any other command that builds or runs fvdep code → `tools/vflab-run <cmd>`. Contract + predicates: `docs/contracts/U1-foundation.md`.
- `tools/vflab-run`: exit = the command's status; 2 = a malformed setting (no remote action); 125 = setup, sync or output mapping failed; a signal, OOM kill or timeout never exits 0. `FVDEP_VFLAB_TIMEOUT` = whole seconds (default 7200); `FVDEP_VFLAB_MEMORY` = the unit's MemoryMax, a K/M/G/T size below the slice's cap (default 24G; at or above → 125: an OOM must stay inside the run, never reach fvapi's processes); stderr closes with the unit's accounting line (`vflab-run: Finished with result: …; Memory peak: …`). Workspaces = `~/gate/ws/fvdep-*` alone; `tools/vflab-reclaim.sh` removes orphaned ones.
- CI gate, once `main`'s CI is green: `bash tools/ci-gate.sh <unit>` (pushes `ci/<unit>`, green only when every shard job + the CodeQL run succeeded with no open alert on the branch; deletes it when green). Until then the full gate runs on vflab alone.
- Step ledger = `.gate/ledger.tsv` in the run's workspace. Each red classifies on the spot before a rerun counts: `tools/vflab-run bash tools/gate-ledger.sh` lists unclassified reds, `… classify LINE product|gate|flake|planted` sets one, `… summary` = per-stage runs, reds by class + seconds.
- `prototype/fvdep/` stays outside the gate (shell, python, lean-style + imports skip it; `vulns` scans its lockfiles) until U14 retires it; a change reaching it → its `Artifacts` smoke.
